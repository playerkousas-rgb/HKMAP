iB20000 數碼地形圖 免費 HK$0

iB20000 是地政總署 1:20 000 數碼地形資料，與紙本 HM20C 同一比例、同一測繪處數據庫。 2026 年 2 月官方價目表列明免費。畫面「HM20C / iB20000」底圖已用官方地形圖 API 顯示這套資料（即時圖磚）。

它不是紙本 HM20C 的彩色掃描 PDF，也不能直接丟進瀏覽器。下載後適合 QGIS／CAD／離線列印。全港約 18 幅圖磚（紙本 HM20C 為 16 張，其中第 1 張是圖例）。

使用地政總署地圖 API

Scout System 透過官方 LandsD Map API 顯示香港地形圖與航空照片，方便童軍設計城市定向及郊野定向。圖磚版權屬香港特區政府地政總署。

按照署方規定，地圖畫面已標示 Lands Department 版權聲明。請勿大量短時間呼叫 API。使用前請閱讀 條款及知識產權告示。

本系統給策劃者畫圖、列印紙圖。參加者用紙圖找檢查點，不是手機 App。紙本 HM20C／郊區地圖仍是山藝考核標準教材。

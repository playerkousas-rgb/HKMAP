設計＝列印

畫面中央的白紙就是列印頁：紙上見到乜，印出嚟就係乜；紙以外唔會印。 流程：① 揀底圖／搜尋地點　② 揀紙張＋比例（可鎖定）　③ 喺紙上放 △ ○ ◎　④ 按「列印地圖」。

城市定向

留空＝按 96 dpi 螢幕假設（高密度／已縮放嘅螢幕會比真實 A4 細）；填咗螢幕左右闊度就按真實大小顯示。

可輸入 1:500 至 1:100 000；常用比例亦可在右上方選單直接選取。

路線會自動暫存在這部瀏覽器。列印頁邊距已改成盡量細（CSS 設為 0 mm；實際仍受瀏覽器／打印機可否無邊框所限）。卡住、想重來：按「↩ 返回」或「清除本機暫存」。網址加 ?reset=1 也可強制清空。

使用地政總署地圖 API

Scout System 透過官方 LandsD Map API 顯示香港地形圖與航空照片，另加 OpenTopoMap 作郊遊圖參考，方便童軍設計城市／野外定向。圖磚版權屬香港特區政府地政總署及 OSM。

按照署方規定，地圖畫面已標示 Lands Department 版權聲明。請勿大量短時間呼叫 API。使用前請閱讀 條款及知識產權告示。

本系統給策劃者畫圖、列印紙圖。參加者用紙圖找檢查點，不是手機 App。

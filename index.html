使用地政總署地圖 API

Scout System 透過官方 LandsD Map API 顯示香港地形圖與航空照片，方便童軍設計城市定向及郊野定向。圖磚版權屬香港特區政府地政總署。

按照署方規定，地圖畫面已標示 Lands Department 版權聲明。請勿大量短時間呼叫 API。使用前請閱讀 條款及知識產權告示。

紙本 HM20C 與郊區地圖仍是山藝考核的標準教材；本系統是設計與預習工具，並非紙本地圖的複製品。

已連結的政府地圖

HM20C 地形圖 — 地政總署測繪處 1:20 000 彩色地形圖，童軍及遠足常用。紙本沒有公開圖磚；本系統連接官方 Topographic Map API （數碼地形圖，含等高線、道路、建築物、小徑），並提供 16 幅圖幅索引飛往對應範圍。

郊遊圖／郊區地圖 — 官方紙本共 5 幅。本系統「郊遊圖」模式以同一套官方地形圖為底，疊加漁護署開放數據：郊野公園、遠足徑、標距柱 （CSDI 空間數據共享平台）。

坐標 — 即時顯示 WGS84 與香港 1980 方格網（EPSG:2326），以及 1 km / 100 m / 10 m 方格，方便對照 HM20C 圖邊數字與指南針方位（方格北／磁北）。
